# 📚 BookVerse

**BookVerse** is a premium, high-performance e-book reading application built with **Flutter**. It combines a modern, sleek **Glassmorphic UI** with a seamless reading experience, specifically optimized for classic Bengali literature.

## ✨ Key Features

- 💎 **Premium Glassmorphic UI:** Modern design with blurred backgrounds and sleek transitions.
- 🌓 **Adaptive Theming:** Switch between professional Dark and Light modes effortlessly.
- ⚡ **Lightning Fast Search:** Instantly filter through a vast collection of books by title or author.
- 📖 **Curated Library:** Built-in support for classics from icons like **Sarat Chandra**, **Manik Bandyopadhyay**, and **Samaresh Majumdar**.
- 🛠️ **State Management:** Powered by **Provider** for clean and scalable code architecture.
- 📱 **Responsive Design:** Fully optimized for all screen sizes with smooth Sliver animations.

---

## 🛠️ Tech Stack

- **Framework:** [Flutter](https://flutter.dev)
- **Language:** [Dart](https://dart.dev)
- **State Management:** [Provider](https://pub.dev/packages/provider)
- **Theming:** Material 3 with Custom Color Schemes
- **Fonts:** [Google Fonts](https://pub.dev/packages/google_fonts)
